Detailed Description

Compile-time helpers of the DYNAMIXEL driver: typed integer literals, exact hook matching, typed register fields and enumeration checks.

Copyright
Copyright (c) 2026 The driver-dynamixel authors. SPDX-License-Identifier: MIT

Everything here is constexpr or used only in unevaluated operands, so it adds no code to the run-time path (handbook C++20 profile, KB-CPP20-006, -008, -020, -021, -025, -026).
