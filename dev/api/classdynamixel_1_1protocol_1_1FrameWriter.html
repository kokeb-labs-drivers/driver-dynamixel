Detailed Description

Builds one instruction packet in a caller buffer, with byte stuffing for protocol 2.0.

Put the parameters, then Finish(). Any write that does not fit, or a protocol 1.0 packet over 253 parameters, makes Finish() return 0: nothing is sent then.
