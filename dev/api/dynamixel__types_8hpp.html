Detailed Description

Public types of the DYNAMIXEL driver: errors, Result<T>, protocol enumerations, replies, statistics and the configuration.

Copyright
Copyright (c) 2026 The driver-dynamixel authors. SPDX-License-Identifier: MIT

Everything here is plain data with no platform dependency, so handlers, tests and tools can include it without the driver template. The configuration defaults follow the ROBOTIS e-Manual (protocol 2.0 at 57 600 bit/s, status packets for every instruction) and the timing values that the manual does not give are documented knobs (docs/configuration.md).
