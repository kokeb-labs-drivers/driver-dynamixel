Detailed Description

Control tables of the DYNAMIXEL servo families, the model catalogue and the unit scales.

One logical register name (Reg) maps to an address, a size and a decoding in every family that has it (Lookup()); a family without it returns Unsupported from the typed calls. The tables are data of the ROBOTIS e-Manual "Control Table" pages (docs/datasheets.yml, docs/control-tables.md), one table per family, checked against them in tests/test_model.cpp. Names the e-Manual spells differently per family (Present Speed, Present Velocity) are one Reg; the decoding (Kind) and the unit scale (ModelInfo, FamilyInfo) differ per family. Families the table does not list (the Pro, P, H, L and Y series) are reached with raw addresses (Family::Generic).
