Detailed Description

A configuration proven valid at build time.

constexpr CheckedConfig kBus{Config{.baud = 1'000'000}}; fails to compile, naming ConfigIsInvalid, when Validate() rejects the configuration. Pass kBus.Get() to the driver; the driver still validates at start-up, for configurations built at run time.
