◆ Error

enum class dynamixel::Error : uint8_t
strong

Why a call failed. Every call of the driver returns one of these in its Result.

Values 0 to 9 are the shared base set; bus-specific values start at 16. [[nodiscard]] on the type: a function that returns a bare Error cannot have it ignored either (KB-CPP20-037).

Enumerator
Ok 

The call succeeded.

NotInitialized 

EnsureInitialized() has not succeeded, or Deinitialize() ran since.

InvalidArgument 

An argument or a Config field is out of range; nothing was sent.

Bus 

A port hook returned false.

Timeout 

No complete reply within the deadline (nothing, or a truncated packet).

DeviceIdMismatch 

The reply came from another ID than the one addressed, or the model differs.

Crc 

The CRC-16 (protocol 2.0) or checksum (protocol 1.0) of a reply did not match.

Busy 

Reserved by the shared set; this driver has no pending state.

DeviceFault 

The servo reported a hardware alert and AlertPolicy::Fail is set.

Unsupported 

The hook, protocol or family does not offer this call.

DeviceError 

The servo rejected the instruction: see GetLastReply() for the error number.

InvalidReply 

A reply the protocol refuses: header, length, instruction or parameter count.

EchoMismatch 

The transmitted bytes were not read back as sent (collision or wiring).

LineFault 

The line carried only 0x00 or only 0xFF: stuck low, stuck high or floating.

NotPermitted 

A destructive instruction without Config::allow_destructive.
