Detailed Description

template<UartPort Port, std::size_t FrameBytes = 512>
class dynamixel::DYNAMIXEL< Port, FrameBytes >

Master of one DYNAMIXEL bus on a platform port.

Lifecycle: construct with the configuration (no I/O), then EnsureInitialized(), use, optionally Deinitialize(). Every call that touches the bus returns Error::NotInitialized until EnsureInitialized() has succeeded, with one exception: the torque-off calls (DisableTorque(), DisableTorqueAll(), DisableTorqueEach(), DisableTorqueAt()) and Reboot() are never refused for the driver's state; they bring the port up themselves (and set the bus baud rate) and write even when the input flush fails.

Optional port hooks, found at compile time:

Hook Used for Without it
bool SetBaudRate(uint32_t baud) noexcept EnsureInitialized(), ApplyConfig() and ChangeBusBaud() set the UART rate The port's own rate stays; ChangeBusBaud() returns Unsupported
void Log(LogLevel, const char* message) noexcept One line per lifecycle event or failure Nothing is logged

A hook declared with the wrong signature is a compile error.

Template Parameters
PortYour class derived from UartInterface<Port>.
FrameBytesSize of the transmit and of the receive buffer, 64 to 4096 bytes (default 512). A transfer that does not fit returns InvalidArgument before anything is sent.

◆ DisableTorqueAt()

template<UartPort Port, std::size_t FrameBytes = 512>
Result< void > dynamixel::DYNAMIXEL< Port, FrameBytes >::DisableTorqueAt ( uint8_t  id,
uint16_t  torque_address 
)
noexcept

Turn the torque off at an explicit address: the stop for a servo whose family is Generic (a model the catalogue does not list) or one that has no Reg::TorqueEnable. It shares the stop path of DisableTorque(): never refused for the driver's state, written even when the input flush fails, up to three attempts. The caller supplies the address from the servo's own control table (64 on the X series in protocol 2.0, 24 on AX/RX/DX).

Parameters
idThe servo ID, or 254 for every servo.
torque_addressThe Torque Enable address (at most 255 in protocol 1.0).
Returns
As DisableTorque(); InvalidArgument for an ID or address the protocol does not have (nothing is sent).

Warning: this writes one byte 0 at the address given, with ID 254 to every servo. A wrong address can set IDs to 0, change the baud rate or silence the servos. Take the address from the e-Manual's control table for the exact model and firmware (64 on the X series, 24 on AX/RX/DX, MX 1.0 and XL-320; the Pro series differ).

Reset a servo's control table to the factory values.

Needs Config::allow_destructive. Reset all (ResetOption::All) also resets the ID to 1 and the baud rate to 57 600 bit/s: the servo then answers at another ID and rate than the bus uses. Protocol 1.0 has no option byte (it resets everything: only ResetOption::All is accepted) and cannot use the broadcast ID; protocol 2.0 refuses reset all on the broadcast ID (the firmware does too). Waits Config::reboot_wait_us afterwards.

Parameters

optionWhat to keep.
Returns
NotPermitted, InvalidArgument or the errors of Write().
